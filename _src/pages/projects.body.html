SynapticOS

Edge AI · Library0

EdgeNN

Zero-allocation C11 library for neural network inference on ARM Cortex-M and Cortex-A. Eighteen operators across Dense, Conv, LSTM, GRU and Transformer layers, INT8 with INT32 accumulation, a deterministic graph runtime and a sub-50 KB flash target.

  • C11
  • ARM

PhD testbed0

Distributed Inference Testbed

The experimental platform of my thesis. Five Raspberry Pi 4 boards on an isolated 802.11ac network and an edge server, driven end to end by the NNPM web application: scenarios, concurrent SSH dispatch, per-layer profiling under tc-netem shaping and compute load, INA260 power traces, the RR and SJF delay model and partition optimisation. Runs without hardware in local mode.

Distributed LLM inference0

HeadSplit

Reference implementation of the SPAWC 2026 paper. Each layer's attention heads are scheduled across devices so attention runs in parallel everywhere, and a speculative intermediate output is forwarded before the FFN completes. PyTorch RPC over WiFi on Raspberry Pi clusters.

  • PyTorch
  • Llama

Discrete-event simulator for resource-aware decoder-only Transformer inference across heterogeneous edge clusters. Models devices, attention heads, projections and FFNs, growing KV caches, and compares EdgeShard, Galaxy and the resource-aware algorithm from the WiOpt 2025 paper.
