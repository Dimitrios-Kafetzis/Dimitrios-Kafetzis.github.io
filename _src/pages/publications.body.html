HeadSplit: Attention Head Partitioning and Inter-Layer Speculation for Distributed Inference at the Edge

Dimitrios Kafetzis, Iordanis Koutsopoulos

A small LLM still exceeds one edge device's memory, and layer-wise splits leave all but one device idle at any moment. HeadSplit schedules each layer's attention heads across devices so attention runs in parallel everywhere, and forwards a speculative intermediate output to the next layer before the FFN finishes, filling the idle interval it creates.

SynapticOS: An Inference-First Runtime Architecture for Neural Processing Units on Resource-Constrained Microcontrollers

Dimitrios Kafetzis

Production combinations of Zephyr or FreeRTOS with TensorFlow Lite Micro treat inference as an application library, leaving memory fragmentation, accelerator-state hygiene and model-lifecycle guards to the application developer. This paper presents the Phase 1 architecture of SynapticOS, which makes them operating-system concerns.

Cross-Core Inference Offload as an Operating-System Service on Dual-Core Microcontrollers

Dimitrios Kafetzis

On NXP's MCXN947 the second Cortex-M33 core has no FPU, DSP extension, TrustZone or MPU. The Phase 3 dual-core architecture of SynapticOS treats that asymmetry as a design input: the AI runtime lives on the capable core, and the application core reaches inference only through a message-based OS service.

Video Quality Monitoring for Remote Autonomous Vehicle Control

Dimitrios Kafetzis, Nikos Fotiou, Savvas Argyropoulos, Jad Nasreddine, Iordanis Koutsopoulos

A blueprint for an integrated video-quality monitoring system for remote autonomous vehicle operation over 4G/5G: onboard data collection, video capture and compression, streaming to edge servers, AI model deployment and proactive decisions on predicted quality. Twenty LSTM, GRU and Transformer variants are benchmarked against DNN and linear baselines on a hybrid field-trial and synthetic dataset, with onboard and edge inference compared.

Large Language Model Partitioning for Low-Latency Inference at the Edge

Dimitrios Kafetzis, Ramin Khalili, Iordanis Koutsopoulos

Decoder-only LLMs generate one token at a time while their key-value caches grow. The paper places attention heads, projections and FFN blocks across edge devices and re-plans as the cache expands, minimising per-token latency under each device's memory limit.

DNN Partitioning and Inference Task Offloading in 6G Resource-Constrained Networks

Dimitrios Kafetzis, Iordanis Koutsopoulos

Each resource-constrained device runs the first layers of its DNN locally and offloads the rest to a base station, where the tasks of different devices couple through scheduling. The paper formulates partitioning for minimum total delay and for fair, balanced delays across devices, and proposes a greedy heuristic for each.
